# OmniDICOM downloads

Installers for [OmniDICOM](https://omnidicom.com), a DICOM viewer for research and education.
Source code is not published here; this repository only hosts release files.

| Platform | File | Notes |
|---|---|---|
| macOS 13 or later, Apple silicon | `OmniDICOM-<version>-macos-arm64.dmg` | Developer ID signed and notarized by Apple |
| Windows 10/11, 64-bit | `OmniDICOM-<version>-windows-x64-setup.exe` | Authenticode signed (Youngrak Choi) |

Each release lists SHA-256 checksums. Start the 14-day trial from inside the app;
licences are sold at https://omnidicom.com/checkout.html.

**Research and educational use only. Not for diagnosis, treatment or clinical decisions.**
